## 2026-09-07 - Adding aria-labels to dynamically generated HTML icon-only buttons
**Learning:** Accessibility gaps (like missing `aria-label`s on icon-only buttons) are often hidden in dynamically generated HTML within template literals (e.g., in vanilla JavaScript apps).
**Action:** When adding accessibility features like `aria-label`s, proactively search and update dynamically generated HTML within JavaScript template literals in addition to static root HTML files.
