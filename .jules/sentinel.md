## 2024-05-18 - [HIGH] Fix Stored XSS via HTML Escaping
**Vulnerability:** User inputs like profile names (`p.name`) and team member emails (`email`) were being injected directly into the DOM via `innerHTML` without sanitization. This allows for Stored Cross-Site Scripting (XSS) if malicious payloads are saved in local storage.
**Learning:** In vanilla JavaScript applications utilizing template literals with `innerHTML` for rendering, failing to sanitize untrusted user data exposes the application to serious XSS vulnerabilities.
**Prevention:** Always implement and enforce a global HTML escaping utility function (e.g., `app.escapeHtml`) to sanitize any dynamic, user-controlled data before it is rendered to the DOM using `innerHTML`.
## 2025-06-05 - [Unescaped Variables in innerHTML Template Literals]
**Vulnerability:** XSS vulnerability where user input variables (`searchQ` and `projectName`) were directly interpolated into HTML strings via ES6 template literals and then assigned to `.innerHTML`.
**Learning:** Developers sometimes assume template literals are inherently safe or overlook the need to explicitly escape individual variables interpolated into strings that will be rendered as HTML via `innerHTML`.
**Prevention:** Always use established HTML escaping utilities (like the existing `app.escapeHtml`) when interpolating user-controlled variables into strings bound to `.innerHTML`. Alternatively, prefer text content manipulation methods (like `.textContent` or `innerText`) when possible, or use a robust DOM sanitization library like DOMPurify before setting `.innerHTML`.
## 2025-06-05 - [CI Capacitor Sync Failure due to Old Node.js Version]
**Vulnerability:** Not a direct application vulnerability, but a pipeline/build stability issue caused by using an outdated `node-version: 20` in GitHub Actions when `@capacitor/cli` explicitly requires Node.js >= 22.0.0.
**Learning:** Build tools and CLI wrappers (like `@capacitor/cli`) often enforce minimum Node.js version requirements that must be explicitly mirrored in CI/CD pipeline configurations. Failure to synchronize the runtime environment with dependency requirements breaks the build pipeline.
**Prevention:** Whenever updating major dependencies or CLI tools, always check their minimum runtime requirements and ensure corresponding updates are made in workflow files (e.g., `ci.yml` `actions/setup-node` version).
