## 2026-06-12 - Array Filter String Allocation Optimization
**Learning:** When filtering large arrays of objects, assigning derived boolean values (like `const match = ...`) before returning them forces all checks to evaluate. If the subsequent checks involve expensive string allocations (e.g., `.toLowerCase().includes()`), this becomes a severe bottleneck. The optimized test showed roughly an 8-10x improvement (e.g., 252ms down to 29ms) simply by returning early on inexpensive checks (like category mismatches or empty queries) before attempting the string searches.
**Action:** Always structure filter and map callbacks with early returns for inexpensive boolean or exact-match checks before executing computationally expensive operations, rather than gathering boolean results into intermediate variables.
