## 2026-08-26 - Add ARIA Labels to Dynamically Generated HTML
**Learning:** When applying accessibility improvements in vanilla JS applications (like adding aria-labels to icon buttons), actively search and update dynamically generated HTML within JavaScript template literals, as these are easily overlooked compared to root static HTML files.
**Action:** Ensure both static files (like index.html) and dynamic generation scripts (like app.js) are thoroughly searched for accessibility gaps before assuming the app is fully accessible.
